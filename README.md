# 🩺 AI Medical Demo Interface

A web-based prototype developed during a 10-week internship project exploring how AI and medical imaging technologies could support reconstructive surgery workflows.

The project explores concepts involving 3D imaging, thermal imaging, ultrasound Doppler sonography, tissue analysis, and visualization through an interactive web interface.

> **Important:** This project is a prototype/demo created for educational and development purposes. It is not a clinically validated medical diagnostic system and should not be used for medical decisions.

## 🚀 Run Locally

Clone the repository:

```bash

```

Navigate to the project:

```bash

```

Then open:

```text
index.html
```

in a modern web browser.

No additional installation is required to explore the static web interface.
